Browser Agent

Connect the panel to a local, OpenAI-compatible LLM endpoint.

Base URL of an OpenAI-compatible server - with or without a trailing /v1.

Slow reasoning models on local hardware: the first-token timeout aborts if the server sends nothing at all; once tokens stream, only the (generous) total cap applies. Leave empty for defaults.

Act mode

Optional overrides for the autonomous agent. Leave blank to reuse the chat settings.

When on, the agent keeps short working notes across steps (re-injected each turn) and picks the reasoning effort for its next step (low/medium/high; "off" disables thinking via chat_template_kwargs where the server supports it). When off, behavior is unchanged.

reasoning_effort is sent only when set; servers that don't support it may reject the request - if act calls fail with HTTP 400, set it back to Default.

Voice

Chrome has built-in speech recognition (used automatically for the mic button). For Firefox, or as a fallback, point this at a whisper-style OpenAI-compatible STT server.

Recorded audio is POSTed to {base}/v1/audio/transcriptions (multipart, with the chat API key if set). The browser asks for microphone permission per site.

Connection troubleshooting
  • Ollama: start it with OLLAMA_ORIGINS="chrome-extension://*,moz-extension://*" ollama serve so it accepts the extension's origin.
  • LM Studio: enable CORS in the local server settings.
  • The test calls GET /v1/models (OpenAI-compatible) on the endpoint.
